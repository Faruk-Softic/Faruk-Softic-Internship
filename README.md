# Faruk-Softic-Internship

This repository contains the code for a study investigating whether LLM-based grading of student psychology papers is consistent, and whether rubric design affects grading outcomes. Course materials and student papers are not shared.

---

## Repository Structure

```
/
├── src/
│   └── config.py               # Central definitions for section keys, labels, weights, and checklist items
│
├── data/
│   └── Grading materials/
│       ├── Rubric_original.docx
│       ├── Rubric_improved.docx
│       ├── Writing_guide.pdf
│       └── Sample_results.pdf
│
├── experiments/                # One numbered subfolder per run (excluded from repo)
├── outputs/                    # LLM grading results; mirrors run folder structure 
│
├── build_prompts.py            # Builds batch_input.jsonl and prompts_example.json for the latest run folder
├── batch_submit.py             # Submits batch_input.jsonl to the OpenAI Batch API, polls for completion, parses and saves results
├── pipelines.json              # Defines grading pipelines (rubric version, checklist on/off, etc.)
├── r_analysis.R                # Merges LLM results with teacher grades; produces plots
└── .gitignore
```

### Run folders

Each experiment is stored in a numbered folder under `experiments/`, and its results are mirrored in a corresponding folder under `outputs/`:

```
experiments/
└── run-xx/
    ├── config.yml                      # Run configuration (model, pipelines, repetitions, etc.)
    ├── batch_input.jsonl               # Generated by build_prompts.py — one request per line
    ├── prompts_example.json            # Example prompts for a single paper (for inspection)
    ├── manifest.json                   # Run metadata, batch status, and token usage
    ├── run-xx_output.jsonl             # Raw API output (saved by batch_submit.py)
    ├── run-xx_results_raw.csv          # Parsed grading results (saved by batch_submit.py)
    └── run-xx_errors.jsonl             # API-level errors, if any (saved by batch_submit.py)

outputs/
└── run-xx/
    └── run-xx_results_raw.csv          # Copy of the parsed results (saved by batch_submit.py)
```

`experiments/` and `outputs/` are excluded from the repository (see below).

## Excluded from the repository

| Excluded | Reason |
|---|---|
| `data/` | Contains student papers and course-related information |
| `experiments/` | Large generated output files; reproducible by running the scripts |
| `allinfo_pseudo.csv` | Pseudonymised course grades — needed only to merge original grades with LLM grades |
| `.env` | Contains API key and local paths |
| `.venv/` | Virtual environment |
| `__pycache__/` | Python cache |

## Setup

### 1. Install dependencies

```bash
pip install openai pdfplumber python-docx python-dotenv pyyaml
```

### 2. Configure environment variables

Set up an `.env` file as follows:

```env
OPENAI_API_KEY=your-key-here
PAPERS_FOLDER=data/Student papers
GRADING_MATERIALS_FOLDER=data/Grading materials
EXPERIMENTS_FOLDER=experiments
OUTPUTS_FOLDER=outputs
RUBRIC_ORIGINAL=Rubric_original.docx
RUBRIC_IMPROVED=Rubric_improved.docx
WRITING_GUIDE=Writing_guide.pdf
SAMPLE_RESULTS=Sample_results.pdf
PIPELINES_FILE=pipelines.json
```

### 3. Configure pipelines

`pipelines.json` defines which rubric version and checklist settings to use per pipeline:

```json
{
  "original": {
    "pipeline_id": "original",
    "rubric_version": "original",
    "include_checklist": false
  },
  "improved": {
    "pipeline_id": "improved",
    "rubric_version": "improved",
    "include_checklist": true
  }
}
```

### 4. Configure a run

Create a numbered folder under `experiments/` (e.g. `experiments/run-11/`) and add a `config.yml`:

```yaml
model: <model-name>
reasoning_effort: medium
reasoning_summary: auto

pipelines:
  - original
  - improved

include_feedback: true
include_resources: true

student_ids: []    # empty list = all papers

repetitions: 3

notes: "Description of what this run is testing."
```

## Usage

### Step 1 — Build prompts

Automatically detects the latest `experiments/run-xx/` folder, loads all papers and grading materials, and writes `batch_input.jsonl`, `prompts_example.json`, and `manifest.json` into that folder.

```bash
python build_prompts.py
```

Inspect `prompts_example.json` or the full `batch_input.jsonl` before submitting to verify the prompts look correct.

### Step 2 — Submit batch

Submits `batch_input.jsonl` to the OpenAI Batch API, polls for completion, and on success:
- saves raw API output as `run-xx_output.jsonl` in the experiments run folder
- parses results and saves `run-xx_results_raw.csv` to both the experiments run folder and the corresponding `outputs/run-xx/` folder
- finalises `manifest.json` with batch status, completion time, and token usage

Press **Ctrl+C** at any time to cancel the batch.

```bash
python batch_submit.py
```

## Output

Each row in `run-xx_results_raw.csv` corresponds to one grading request, identified by a custom ID in the format:

```
run-xx__studentid__pipelineid__run1
```

### Grade weights

| Section | Weight |
|---|---|
| Introduction | 30% |
| Methods | 15% |
| Results | 15% |
| Discussion | 30% |
| Language & Style | 10% |

## Analysis

`r_analysis.R` merges LLM results with teacher grades from `allinfo_pseudo.csv` into `combined.csv`, and produces plots comparing LLM grades to teacher grades.
